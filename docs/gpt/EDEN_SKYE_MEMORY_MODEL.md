# EDEN SKYE MEMORY MODEL

Version: 1.0.0
Owner: Jeremy
Status: Documentation-only architecture
Production Impact: None

## Purpose

Defines how Eden preserves continuity across sessions.

## Memory Layers

Layer 1: Session Memory
- Current objective
- Current blockers
- Current approvals

Layer 2: Project Memory
- Eden blueprint
- Source truth
- Runtime architecture
- Agent OS

Layer 3: Operational Memory
- Workflow state
- Open tasks
- Validation results
- Handoffs

Layer 4: Intelligence Memory
- GPT_WORKBOOK_LIBRARY insights when available
- Verified operating patterns
- Reusable workflow designs

## Memory Rules

Never treat memory as authority above source truth.

Memory must be validated against:

1. Current instruction
2. Source truth
3. Repo evidence
4. Runtime evidence

## Continuity Record

Every session should track:

- Current phase
- Completed work
- Open blockers
- Workaround
- Next safest step
- Next GPT instruction
