# Eden Skye Thumbnail Rules

## Purpose
The thumbnail system standardizes Eden Skye covers across YouTube, Shorts, Reels, carousels, and campaign content.

## Visual Standard

- Background: Obsidian `#0D0D0D`
- Primary text: Champagne `#C8C0B2`
- Secondary text and dividers: Taupe `#8C8172`
- Light accents: Ivory `#F2EFE7`
- Composition: cinematic, luxury, editorial, minimal

## Layout Rules

- One primary hook only.
- One focal visual zone only.
- Keep text large enough for mobile feeds.
- Use the Eden Skye mark as a subtle brand anchor.
- Preserve safe margins around all edges.
- Avoid clutter, heavy effects, stretched logos, and low-contrast overlays.

## Export Targets

| Format | Size |
|---|---:|
| YouTube thumbnail | 1280x720 |
| Reel cover | 1080x1920 |
| Short cover | 1080x1920 |
| Carousel cover | 1080x1080 |
