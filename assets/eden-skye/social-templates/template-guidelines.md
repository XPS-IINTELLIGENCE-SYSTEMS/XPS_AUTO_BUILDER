# Eden Skye Social Template Guidelines

## Purpose
These templates standardize Eden Skye social content across Instagram, YouTube, X, and LinkedIn.

## Core Rules

- Use Obsidian `#0D0D0D` as the default background.
- Use Champagne `#C8C0B2` for primary type and logo marks.
- Use Taupe `#8C8172` for secondary labels and divider lines.
- Use Ivory `#F2EFE7` when a light editorial layout is needed.
- Maintain generous negative space.
- Keep logo marks away from platform UI overlays.
- Use large, legible typography for thumbnails and mobile-first content.

## Template Zones

- Header zone: platform-safe brand or title placement.
- Focal zone: image, avatar, creator visual, or campaign subject.
- Message zone: primary content hook or title.
- Brand zone: Eden Skye monogram, watermark, or handle.

## Export Standard

Export PNG versions from SVG master files using lowercase kebab-case filenames.
