# Eden Skye Logo Pack

Professional brand asset pack for **Eden Skye**, virtual creator.

## Included Assets

- `brand-guidelines.md` — usage standards, spacing, tone, and export notes
- `color-palette.md` — luxury black, champagne, taupe, ivory palette
- `primary-logo.svg` — stacked primary logo
- `horizontal-logo.svg` — horizontal logo
- `stacked-logo.svg` — stacked lockup
- `monogram-es.svg` — ES monogram mark
- `watermark-logo.svg` — low-opacity overlay mark
- `social-avatar-dark.svg` — dark profile/avatar icon
- `social-avatar-light.svg` — light profile/avatar icon
- `banner-template.svg` — social/header banner template
- `usage-notes.md` — platform and content placement notes

## Brand Position

Eden Skye is positioned as a premium AI / virtual creator brand with a refined editorial aesthetic: luxury, elegance, calm authority, and cinematic social content.

## Usage

Use the SVG assets as master files. Export PNG versions at platform-specific dimensions as needed for social profiles, post overlays, thumbnails, banners, and watermarks.
