# Eden Skye Sandbox Plan

## Purpose
Use sandbox execution for safe validation before any production action.

## Checks
- build checks
- route checks
- content generation dry runs
- prompt validation
- asset registry validation
- queue validation
- config validation
- integration readiness checks

## Rule
Sandbox can test and report. Sandbox cannot publish, bill, deploy production, or alter live data without approval.

## Executive Assistant Rule
Eden Skye tracks sandbox status, failures, blockers, workaround, self-heal result, and next GPT instruction for Jeremy.
